# Telegram Support Bot

Telegram-бот для обработки пользовательских заявок и связи с менеджером.

Проект реализован на Python с использованием aiogram и PostgreSQL. Бот поддерживает создание заявок, просмотр их статусов, управление заявками менеджером и обмен сообщениями между пользователем и менеджером.

## Возможности

### Пользователь

- Создание заявки
- Ввод имени, номера телефона и описания проблемы
- Просмотр своих заявок
- Просмотр статуса заявки
- Связь с менеджером
- Отправка сообщения менеджеру
- Получение ответа от менеджера

### Менеджер

- Просмотр всех заявок
- Просмотр заявок по статусам
- Взятие заявки в работу
- Завершение заявки
- Получение уведомлений о новых заявках
- Ответ пользователям

## Стек

- Python
- aiogram
- PostgreSQL
- asyncpg
- python-dotenv

## Статусы заявок

- NEW — новая заявка
- IN_PROGRESS — заявка взята в работу
- DONE — заявка завершена

## Установка

### Клонировать репозиторий:

```
git clone <repository-url>
cd telegram_support_bot
```

### Создать виртуальное окружение:

```
python -m venv venv
```

### Активировать его в Windows:

```
venv\Scripts\activate
```

### Установить зависимости:

```
pip install -r requirements.txt
```

## Настройка

### Создать файл .env в корне проекта:

```
BOT_TOKEN=your_bot_token
DATABASE_URL=your_database_url
MANAGER_ID=your_telegram_id
MANAGER_PHONE=+7XXXXXXXXXX
```

## Запуск

```
python main.py
```

После запуска бот подключается к PostgreSQL и начинает принимать сообщения через Telegram.

## База данных

Проект использует PostgreSQL.

### Основные таблицы:

`users`

Хранит пользователей бота и их роли.

Роли:

- user
- manager

`requests`

Хранит пользовательские заявки:

- имя;
- номер телефона;
- описание проблемы;
- Telegram ID пользователя;
- статус;
- дату создания.

## Архитектура

Проект разделён на несколько частей:

- `main.py` — обработчики Telegram-сообщений, FSM и основная логика бота;
- `database/db.py` — работа с PostgreSQL;
- `keyboards/keyboards.py` — Telegram-клавиатуры и inline-кнопки.
